
# Dự án văn phòng phẩm website

## Giới thiệu dự án
Đây là **mã nguồn quản lý** dữ liệu mua bán đồ dùng học tập trong *tháng 10*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
| --- | --- |
| `data/` | Chứa file Excel quản lý đơn mua hàng tháng 10 |
| `logs/` | Chứa file log hệ thống và file báo cáo (shop.log,daily_report.txt) |
| `docs/` | Chứa tài liệu nhập hàng |

## Lệnh liệt kê nội dung dự án
```powershell
Get-ChildItem -Recurse -Force
```
## Danh sách công việc

-   [x] Tạo cấu trúc thư mục dự án
    
-   [ ] Lọc báo cáo lỗi trong file log
